Privacy policy

Prepared October 26, 2026. Applies when this site is published.

Information used by the application

NYCAT uses Google account information, including the verified email address and account identifier, for sign-in and application access. It records practice responses, results, and available timing and session information in its local database.

Google Drive access

The backup connection requests Google's drive.file permission. This limits access to files created by the application or specifically made available to it. It does not request unrestricted access to the entire Google Drive.

The operator's Google account is used for backup authorization. The connection supports Cloud Sync and encrypted project and database recovery archives. Recovery archives can include application files, private configuration, practice records, project logs, and surviving project chat history.

Storage and sharing

Working data and renewable authorization credentials are stored in private local application files. Recovery archives are encrypted before cloud upload. Google processes information needed for sign-in and Drive storage under its own policies.

When completion email is enabled, a results report is sent through the configured email provider to the student and copied privately to the operator. In the operator's Student Mode, a duplicate copy to the operator is omitted.

This information site is hosted by GitHub Pages. It does not include advertising, analytics scripts, or forms. GitHub logs visitor IP addresses for security purposes. See the GitHub Privacy Statement for its hosting practices.

Retention and control

Records and recovery copies remain under the operator's control and may be retained for history and recovery. Marking a record inactive does not erase it from existing backups. Contact the operator to ask about access, correction, retention, or deletion.

The Google account owner can revoke NYCAT's access through Google Account connections. Revocation stops authorized Drive operations until access is renewed; it does not automatically remove existing local data or Drive archives.

Use of information received from Google APIs must follow the Google API Services User Data Policy, including its Limited Use requirements. Publication of this information page does not represent Google verification or approval.
